Le fichier config.js contient une erreur

La démonstration ne peut pas démarrer. La cause la plus fréquente : une virgule oubliée, un guillemet non fermé, ou un nombre écrit avec une virgule (18,40) au lieu d'un point (18.40).

Annulez votre dernière modification dans GitHub (onglet « History » du fichier) ou relisez les lignes modifiées. Le README explique comment repérer l'erreur.
